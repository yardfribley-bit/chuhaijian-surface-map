# 产品范围 — 攻击面测绘

## 目标用户

安全运营 / 研发，需要在**授权环境**了解 Web 暴露面，而不做完整渗透测试。

## In Scope

- 目标可达性与基础 HTTP 特征  
- 公开路径 / API 端点枚举（在授权与限流内）  
- 技术栈指纹（框架、服务器头等公开信息）  
- 暴露面摘要报告（Markdown / JSON）  

## Out of Scope

- 漏洞验证与利用（Injection / XSS / SSRF / 越权攻击等）  
- 密码爆破、凭证填充  
- 以破坏或驻留为目的的操作  
- 源码深度白盒（见 codeaudit）  

## 与 codeaudit 的边界

| | surface-map | codeaudit |
|--|-------------|-----------|
| 输入 | 授权 URL + scope | 源码路径 |
| 网络 | 有限只读探测 | 默认无业务流量 |
| 输出 | 端点与暴露面地图 | 代码风险与修复建议 |
| 利用 | 无 | 无 |
